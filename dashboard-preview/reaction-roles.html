🌈 Color roles

A ready-made set of 12 gradient name colors. It creates the roles and posts a “Pick your name color” panel. Run it again to add any that are missing. Lumo needs Manage Roles, and its role must sit above the color roles.

About gradients: Discord only draws a two-color gradient on a server that has unlocked Enhanced Role Styles (a perk you unlock with 3 Server Boosts, separate from the Boost level). Without it the roles still work and show just the first color of each gradient.

LLumoBOT#roles
Pick your name color
Pick one: react to choose your color. React again to switch.
