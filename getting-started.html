Get started

Set up Lumo in five steps

From adding the bot to a server that runs itself. Each step takes about a minute.

The five steps

  1. 1

    Add Lumo to your server

    You need the Manage Server permission. Discord shows the permissions Lumo asks for, and the FAQ explains each one. It's free to add.

    Add to Discord
  2. 2

    Run /setup status

    Type it in any channel (it needs the Administrator permission). You get a private checklist of what's set up and what isn't, with the exact command to fix each gap. It changes nothing.

  3. 3

    Try /help

    A private tour of every command with a Try it line on each page. It also points you to the web dashboard (beta) for reaction roles, Customize, giveaways and polls. Then catch tonight’s stars with /sky watch once an admin turns on Starkeepers in the dashboard, /play a song from a voice channel, or run /game to open the game hub.

  4. 4

    Set up welcome, autorole, roles, giveaways and polls

    All free. Pick what you need:

    • /setup welcome picks the channel for welcome messages (new members get a welcome card; change its wording in the dashboard's Welcome page)
    • /setup autorole gives new members a role the moment they join
    • In the web dashboard (beta), log in with Discord, pick your server and open Roles to post a reaction-role panel (people react to pick roles) or add 12 gradient color roles
    • /giveaway start and /poll create (Administrators) run a giveaway or a poll with buttons, or use their pages in the dashboard

    Tip: keep Lumo's role above the roles it hands out, or Discord won't let it assign them. How to fix it.

  5. 5

    Get Premium (optional)

    Premium switches on the AI features for your whole server: chat that understands pictures, with web search, live voice, images, video and a custom name, personality, avatar and banner (set in the web dashboard). It's $4.99 a month per server, with no subscription. Run /premium status any time to see your plan and usage.
